# DD-003: Error Origin and Classification

**Date:** 26-11-2026  
**Status:** Accepted  
**Area:** Error System

## Context

An error needs to communicate more than its severity and numerical code.

Angry Rocket consists of multiple architectural layers, and different subsystems can produce errors with similar numerical values.

The error representation must distinguish where an error originated from what kind of error occurred.

## Decision

The error representation contains the following fields:

### Layer

Identifies the architectural layer where the error originated.

Examples include:

- Core
- Runtime

The layer describes the origin of the error, not the layer currently handling it.

### Severity

Identifies the severity of the error.

Severity values are individual identifiers, not bit flags.

The severity classification does not determine whether an operation succeeded. The Result API remains responsible for representing operation success or failure.

### Domain

Identifies the category or subsystem associated with the error.

Examples include:

- Common
- Memory
- Filesystem
- Threading
- Window
- Networking

Domains classify errors independently of their architectural origin.

### Source

Identifies the source or namespace associated with the error code.

Examples include:

- Angry Rocket-defined errors.
- Windows system errors.
- POSIX errors.
- GLFW errors.

The source identifies the error-code provider or namespace, not necessarily the underlying operating system.

### Code

Contains the actual error identifier.

The interpretation of the code depends on its associated error classification and source.

## Consequences

- Errors can be traced to their originating architectural layer.
- Error categories remain independent of architectural layers.
- Errors originating from external libraries can be represented without losing their original error identifiers.
- Different error-code namespaces can coexist without treating their numerical values as interchangeable.
- Error formatting and inspection can use all five fields to provide meaningful diagnostics.

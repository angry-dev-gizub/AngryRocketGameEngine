# DD-005: Error Classification and Identification

**Date:** 2026-11-24  
**Status:** Accepted  
**Area:** Architecture / Error Handling

### Context

The packed error representation requires a consistent classification system.

Errors can originate from different parts of the engine and may have different levels of severity.

The system must distinguish the severity of an error from the domain that defines its code.

### Decision

Every packed error consists of three independent identifiers.

**Severity**

Severity describes the classification of the reported condition.

The following severity identifiers are defined:

- `NONE`: No severity assigned.
- `LOG`: Informational condition.
- `WARNING`: Warning condition.
- `ERROR`: Error condition.
- `FATAL`: Fatal condition.

Severity identifiers are individual values, not flags, and must not be combined using bitwise OR.

Severity describes an error condition. It does not determine whether an operation succeeded or failed.

**Domain**

A domain identifies the group in which an error code is defined.

Different domains may use the same numeric error code without referring to the same error.

A common domain may contain errors shared across multiple subsystems.

**Code**

The code identifies a specific error within its domain.

The combination of domain and code identifies an error definition.

### Consequences

- Errors can be classified independently of the subsystem reporting them.
- Error codes can be reused across different domains.
- Common errors can be shared across multiple subsystems.
- Severity can describe the importance of a condition without determining operation success.
- Error definitions can be extended by introducing additional domains and codes.

### Alternatives Considered

**Using severity as an indication of operation success**

Rejected because severity and operation success represent different information.

**Using globally unique error codes**

Rejected because domain-local codes provide a clearer organizational structure and avoid requiring a globally coordinated code space.
